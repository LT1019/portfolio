# Hans Werner A. Huyo — Portfolio

Personal portfolio website. It is plain HTML, CSS and JavaScript with no build step, deployed on Vercel.

## Files

- `index.html` — page content (edit this to add jobs, projects, skills)
- `style.css` — styling, including dark mode
- `script.js` — mobile menu and dark mode toggle
- `assets/profile.jpg` — profile photo (the page shows initials if it's missing)

## Run locally

Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Deploy

Every push to the `main` branch on GitHub redeploys the site on Vercel automatically.
